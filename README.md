
# RevQuest — Stock Market Dashboard

RevQuest is a stock market dashboard built with Python. It allows users to explore historical stock prices and view simple mathematical estimates of future prices.

## Features

- Search for stocks using ticker symbols
- View historical closing prices
- Review stock performance metrics
- Choose historical time periods
- Generate 7, 30, or 90 business-day price estimates
- View historical and forecast data in tables

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- NumPy
- yfinance

## How to Run

1. Install Python.
2. Install the required packages:

   pip install -r requirements.txt

3. Start the dashboard:

   streamlit run app.py

4. Open the local URL displayed in the terminal.

## Disclaimer

Forecasts are based on a simple linear trend and are not reliable predictions of future market prices. This project is for educational purposes only and does not provide financial advice.
